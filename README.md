# TurraniX 1.1.0 Update

Here's a detailed summary of the recent changes to the TurraniX application.

---

## 🚀 Version 1.1.0 Release Notes

This release focuses on improving the user experience with bug fixes, new features, and a fresh UI design.

### Bug Fixes

* **Fixed loading issues:** The Slot Booker and Room ID/Pass Modal now load correctly without any issues.
* **Modal behavior:** The Match Details Dialog now closes properly, improving overall navigation.
* **Smoother rendering:** Improved the smoothness of component rendering for a more fluid feel.

### New Features

* **Dialog component:** A new dialog component from `@/components/ui/dialog` has been added to wrap the Slot Booker.
* **Close button:** Added a close button with a cross icon to the top-right corner of the dialog for easier dismissal.
* **State management:** Improved the handling of state variables (`showSlotBooker` and `showRoomModal`) for better control and reliability.

### Changes

* **Component updates:** `MatchCard.jsx`, `SlotBooker.jsx`, and `RoomIdPassModal.jsx` have all been updated to handle the new dialog and state logic.

---

## 🎨 Design and Interface Updates

We've refreshed the user interface to give TurraniX a more modern and cohesive look.

### All Changes to the Profile Page

Here is a summary of the changes we've made to the `ProfilePage.js` file:

* **Updated Color Palette:** The entire color scheme has been changed to a new, modern, and energetic palette of **deep purple**, **vibrant magenta**, and **cool teal**. This includes new gradients, button colors, and badge hues.
* **Modified Referral Share Button:** The `Share Referral` button is now a vibrant **yellow (`bg-yellow-400`)** and is slightly larger with a new hover effect (`hover:bg-yellow-500`).
* **Simplified Referral Message:** The message that is shared has been simplified for better readability and a more direct call to action. It now includes emojis and focuses on the referral code and sign-up link.

### Changes to the Wallet Interface

We've also made some adjustments to the wallet interface to make it more user-friendly.

* **Simplified Design:** The layout has been streamlined for a cleaner, less cluttered look.
* **Improved Transaction History:** The transaction history section is now more organized and easier to read.
* **Branding Update:** The UI elements and colors have been updated to align with the new TurraniX brand, providing a consistent experience across the app.
